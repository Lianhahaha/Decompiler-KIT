Read and follow `AGENTS.md` in this repo.

If the user asked you to fetch, clone, or set up this kit, install it automatically by
running the bootstrapper for the current OS (`bootstrap.ps1` or `bootstrap.sh`). Do not ask
which tools to install and do not download tools manually. Then activate `env.ps1` /
`env.sh`, verify `tools/install.log`, and report `GAME_RE_ROOT`.
